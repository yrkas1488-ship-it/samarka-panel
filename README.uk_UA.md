## 🌟 Ключові особливості Samarka Panel

- **🎨 Ексклюзивний редизайн інтерфейсу**:
  - Верхній статус-бар: моніторинг `HOST`, пошуковий рядок `[Search: Cmd+K]`, швидкість трафіку в реальному часі (`↓ ... Mbps`, `↑ ... Mbps`), навантаження RAM та CPU у золотаво-бурштиновій палітрі (`#f59e0b`).
  - **Active Inbounds**: картки активних вхідних підключень з великим номером порту (`:8443`, `:443`), параметрами `sni`, `ShortId`, кількістю користувачів, зеленою кнопкою **`Get QR/Link`** та перемикачем миттєвого вмикання/вимикання `Active`.
  - **Live Sniffer**: інтерактивна таблиця з'єднань (`Time` | `Client` | `Protocol` | `Target Domain` | `Status`) з кольоровими статусами (`Direct 🟢`, `Proxy 🔵`, `Blocked 🔴`) та автооновленням трафіку в реальному часі.
  - Лаконічна навігація: лише потрібні розділи у сайдбарі (Дашборд, Вхідні & Reality, Клієнти, Вихідні, Маршрутизація, Налаштування).
- **👑 Архітектура кластера серверів**:
  - **Головний-Головний сервер (Super-Master)**: централізований пульт моніторингу та координації всіх серверів мережі з миттєвим додаванням підпорядкованих вузлів за посиланням та валідними API-токенами.
  - **Головний сервер (Master)**: керування клієнтами, генерація ключів і швидких посилань `samarka://join?...` для підпорядкованих вузлів.
  - **Вторинний сервер (Worker)**: режим Origin для CDN мереж або вузол Подвійного VPN (Relay/Exit).
- **☁️ Обхід блокувань через CDN (порт 443 / XHTTP)**:
  - Готові пресети для Cloudflare та популярних CDN-провайдерів.
  - Підтримка методу `OPTIONS` (з мапінгом у POST через Nginx), заголовка `X-Cache` та обфускації padding `dc`.
  - Вбудоване створення CDN Inbound на 443 порту в 1 клік прямо з веб-інтерфейсу.
- **⚡ Швидкі шаблони VLESS Reality (порт 8443)**:
  - Автоматичне маскування під надійні домени.
  - Готові конфігурації Reality TCP та Reality gRPC зі згенерованими ключами X25519.
- **🌐 Прив'язка домену та SSL**:
  - Окрема вкладка в налаштуваннях з інтеграцією Cloudflare DNS, автоматичною генерацією сертифікатів Let's Encrypt та шаблоном Nginx Reverse Proxy.
- **🌍 3 підтримувані мови**:
  - Українська (`uk-UA`)
  - English (`en-US`)
  - Русский (`ru-RU`)
  - Інтерактивний вибір мови безпосередньо під час встановлення в консолі.

## 🚀 Швидкий старт

Встановлення виконується однією командою в терміналі Linux (Ubuntu, Debian, CentOS, AlmaLinux, Rocky, Alpine, Arch):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/yrkas1488-ship-it/samarka-panel/main/install.sh)
```

### Параметри за замовчуванням під час встановлення:
* **Порт веб-панелі:** `2053` (налаштовується)
* **Прямі вхідні підключення Reality:** `8443`
* **CDN-підключення:** `443`
* **База даних:** SQLite (`/etc/x-ui/x-ui.db`) або PostgreSQL

Після завершення встановлення в терміналі з'являться облікові дані та адреса для входу. Під час першого відкриття веб-панелі вас зустріне зручний **Майстер первинного налаштування**, який допоможе обрати роль сервера та за потреби налаштувати CDN в 1 клік.

Керування службою на сервері здійснюється командою `samarka` або `x-ui`.

## 📦 Бази даних

Samarka Panel підтримує два типи сховища:

1. **SQLite** (за замовчуванням) — один файл бази даних `/etc/x-ui/x-ui.db`. Ідеально підходить для автономних серверів та навантажень до 500+ активних клієнтів.
2. **PostgreSQL** — рекомендується для великих розподілених кластерів з великою кількістю нод і користувачів. Інсталятор може налаштувати локальний PostgreSQL автоматично або підключитися до зовнішнього сервера.

Міграція з SQLite на PostgreSQL у будь-який момент:
```bash
x-ui migrate-db --dsn "postgres://user:password@127.0.0.1:5432/samarka?sslmode=disable"
```

## ⚙️ Змінні оточення

| Змінна | Опис | За замовчуванням |
|---|---|---|
| `XUI_PORT` | Порт веб-панелі | `2053` |
| `XUI_DB_TYPE` | Тип БД (`sqlite` або `postgres`) | `sqlite` |
| `XUI_DB_DSN` | DSN підключення до PostgreSQL | — |
| `XUI_DB_FOLDER` | Шлях до папки бази SQLite | `/etc/x-ui` |
| `XUI_INIT_WEB_BASE_PATH` | Базовий шлях URL панелі | `/` |
| `XUI_ENABLE_FAIL2BAN` | Захист від підбору паролів та обмеження IP клієнтів через Fail2ban | `true` |
| `XUI_LOG_LEVEL` | Рівень логування (`debug`, `info`, `warning`, `error`) | `info` |
